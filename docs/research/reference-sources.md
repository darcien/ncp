# Note: sources of evidence

Date: 2026-10-10. This note tells how to read the older reports. The older
reports stay as they are.

**Rule.** AGENTS.md gives the rule. Prior art comes from the official MCP
specification, SDKs and test parts, and from tools of established vendors.
A small project of one person is an example only.

**Evidence.** These sources can give the reason for a decision:

- the MCP specification and its official extensions
- the official SDKs (TypeScript, Python, Go, and Rust `rmcp`)
- the MCP Inspector and the conformance suite
- Claude Code, Claude Desktop, OpenAI Codex CLI, Gemini CLI, VS Code,
  Cursor, Zed and Goose

**Examples only.** These tools are in older reports, for example
`interface-and-config.md`, `agent-config-formats.md` and
`mcp-client-oauth.md`. They are examples only:

- `openclaw/mcporter`, `apify/mcpc`, `lydakis/mcpx`, `philschmid/mcp-cli`
- `knowsuchagency/mcp2cli`, `f/mcptools`, `IBM/mcp-cli`
- Factory droid

**Older decisions.** A decision that took an idea from these examples
keeps its own reason. When such a decision changes, compare it with the
sources in the evidence list.
